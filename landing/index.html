How it works

From signup to your first query in minutes

CountyLayer speaks MCP (Model Context Protocol) — the open standard AI tools use to connect to external data. You don't need to write a scraper or manage infrastructure.

1

Subscribe & get your API key

Choose a plan below and check out securely with Stripe. Your personal API key arrives by email within a few minutes.

2

Connect your AI client

Add CountyLayer as an MCP server in Claude Desktop, Claude Code, or any MCP-compatible client using your key:

{ "mcpServers": { "countylayer": { "url": "https://countylayer.com/mcp", "headers": { "Authorization": "Bearer YOUR_API_KEY_HERE" } } } }
3

Start querying

Your agent can now search by address, look up an owner's full property portfolio, or pull a complete property record by account number — live, structured data, no scraping required.

FAQ

Common questions

What data is included?

Property records for Tulsa County — owner name and mailing address, property address, legal description, sale history, physical characteristics, and assessed value — sourced from Tulsa County's official parcel records via INCOG's public data feed.

Do I need to know how to code?

Not necessarily. If you're using an AI client like Claude Desktop that supports MCP, adding CountyLayer is a short config snippet (shown above) — no coding required. If you're building your own agent or application, you can call the same API directly.

What is MCP, and which tools does this work with?

MCP (Model Context Protocol) is an open standard that lets AI assistants connect to external data sources and tools. CountyLayer works with any MCP-compatible client, including Claude Desktop and Claude Code, as well as custom AI agents built to speak MCP.

What happens if I go over my monthly quota?

Once you reach your plan's monthly query limit, further requests return an error until your billing cycle resets. Requests are never silently throttled or queued — you'll know immediately if you need to upgrade.

Can I cancel anytime?

Yes. Subscriptions are billed monthly or yearly with no long-term contract. Click the "manage your subscription" link in your API key email to cancel, update your payment method, or change plans through a secure Stripe-hosted portal - or email support@countylayer.com. Cancellation takes effect at the end of your current billing period.
